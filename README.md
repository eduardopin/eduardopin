## Executive technical profile

I am an Infrastructure, Cloud and Platform Engineering leader focused on reliable, secure and cost-aware technology operations.

My work is centered on the intersection of **cloud infrastructure**, **SRE**, **platform engineering**, **DevSecOps**, **FinOps**, **observability**, **CI/CD modernization**, and **database/platform operations**.

This GitHub profile is a **public, sanitized portfolio**. It does not expose employer code, customer data, internal architectures, credentials, production hostnames, or proprietary implementation details.

## Operating principles



- **Reliability first:** define service expectations, instrument the system, reduce toil and improve incident response.
- **Security in the delivery path:** guardrails, hardening, secrets management and scanning must be part of the pipeline.
- **Cost is an engineering signal:** cloud cost should be visible, actionable and tied to workloads.
- **Platform as a product:** golden paths should reduce cognitive load and improve delivery speed.
- **Documentation as evidence:** architecture decisions, runbooks and operating models are part of the engineering output.
